# VLM as Reward Models for RL

This repository reproduces and extends the concepts from the paper *Vision Language Models are In-Context Value Learners* (GVL). It provides a complete pipeline to use Vision-Language Models (VLMs), specifically running via a local vLLM server, as zero-shot or few-shot reward models for robotic tasks. The pipeline currently supports and evaluates on MetaWorld environments.

## Features
- **Autoregressive Value Prediction**: Evaluates multi-frame videos using a single VLM prompt that predicts the task completion percentages sequentially.
- **Input Observation Shuffling**: Shuffles intermediate input frames to eliminate temporal biases, forcing the model to deeply understand the visual state of the task rather than simply assigning monotonically increasing values.
- **In-Context Examples**: Configurable option to provide a "ground truth" expert rollout to the VLM to improve its accuracy.
- **Reward Metrics (VOC & Spearman)**: Computes the Value-Order Correlation (VOC) and Spearman's rank correlation to measure how effectively the VLM can recover the true chronological progress of the sequence from shuffled inputs.

## Setup

### Prerequisites
1. A conda environment (`VLM_RM`) containing Python and necessary packages (e.g., `aiohttp`, `pyyaml`, `scipy`, `numpy`).
2. A running instance of a `vLLM` server serving a Vision-Language Model (e.g., `cyankiwi/Qwen3-VL-4B-Instruct-AWQ-4bit`).

### Configuration
1. **`.env`**: Configure your environment variables to point to your vLLM server.
   ```env
   VLLM_API_URL=http://localhost:8000/v1/chat/completions
   MODEL_NAME=cyankiwi/Qwen3-VL-4B-Instruct-AWQ-4bit
   ```

2. **`configs/configs.yaml`**: The primary configuration file for the pipeline.
   - `experiment_name`: Sets the output folder name for the rewards and metrics.
   - `frames_in_context`: Defines the number of frames evaluated per rollout (e.g., `30`).
   - `experiment_shuffle_frames`: Set to `true` to shuffle frames before feeding them to the VLM.
   - `experiment_in_context_examples`: Set to `1` to include an in-context demonstration, or `0` for zero-shot.

## Usage

### 1. Collect Rewards (`src/collect_rewards.py`)
This script uses `aiohttp` to asynchronously send batches of shuffled rollout frames to the VLM for evaluation. It strictly anchors the initial `frame_000` to a `0%` progress score and asks the VLM to predict the rest.

```bash
conda activate VLM_RM
python src/collect_rewards.py
```
*Outputs are saved to `output/metaworld_rewards/<experiment_name>/` as `*rewards.json` files.*

### 2. Compute Metrics (`src/compute_metrics.py`)
This script analyzes the predicted rewards generated by the VLM. It specifically "un-shuffles" the frame predictions back into chronological order and compares them against the ground-truth step sequence.

```bash
conda activate VLM_RM
python src/compute_metrics.py
```
*Calculates Spearman and VOC metrics and prints them to the terminal. Saves detailed metrics to `output/metaworld_rewards/<experiment_name>/metrics.json`.*

## Task Descriptions
The pipeline currently evaluates on the following MetaWorld `v3` environments:
- `drawer-open-v3`
- `button-press-v3`
- `peg-insert-side-v3`
- `pick-place-v3`

Task descriptions have been meticulously written with visual grounding in mind (e.g., specifying the "Sawyer robot arm" and exact actions) to provide maximum context to the VLM.
